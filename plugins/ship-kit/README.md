# ship-kit

Claude Code plugin for building software step by step: pick the next task, build it, write and run
tests, open and review pull requests, and close the card once it's merged.

- **Install and set up:** see the [setup guides](../../README.md#set-up--pick-your-computer).
- **How to use it:** [ship-kit guide](../../docs/ship-kit.md).
- **Problems:** [troubleshooting](../../docs/troubleshooting.md#ship-kit).
