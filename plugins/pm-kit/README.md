# pm-kit

Claude Code plugin for managing an Asana project board with your team's rules built in: add cards
correctly, comment, set up a new board, clean up an existing one, and build a progress page.

- **Install and set up:** see the [setup guides](../../README.md#set-up--pick-your-computer).
- **How to use it:** [pm-kit guide](../../docs/pm-kit.md).
- **Problems:** [troubleshooting](../../docs/troubleshooting.md#pm-kit).
